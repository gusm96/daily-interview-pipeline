# [Q187] Spring Boot의 내장 웹 서버와 커스터마이징

## Spring Boot 내장 웹 서버 사용의 장점 및 커스터마이징

### 1. 핵심 정의

Spring Boot는 별도의 웹 서버 설치 없이 애플리케이션 자체에 웹 서버(Tomcat, Jetty, Undertow 등)를 포함하여 실행할 수 있도록 지원합니다. 이는 JAR 파일 하나로 애플리케이션을 배포하고 실행할 수 있게 하는 "실행 가능한 JAR"의 핵심적인 특징입니다.

### 2. 동작 원리 및 장점

*   **간편한 배포 및 실행:** 외부 웹 서버에 의존하지 않으므로, 애플리케이션 빌드 시 웹 서버까지 함께 패키징되어 JAR 파일 하나만으로 어디서든 `java -jar` 명령어를 통해 쉽게 실행할 수 있습니다. 이는 배포 과정을 단순화하고 환경 설정 오류를 줄여줍니다.
*   **개발 생산성 향상:** 개발 환경과 운영 환경 간의 일관성을 유지하기 용이하며, 개발자가 웹 서버 설정에 대한 부담 없이 비즈니스 로직 개발에 집중할 수 있도록 돕습니다.
*   **마이크로서비스 아키텍처에 적합:** 각 서비스가 독립적인 실행 단위를 가지는 마이크로서비스 아키텍처에서, 서비스별로 내장 웹 서버를 포함하여 독립적으로 배포하고 관리하는 데 매우 효율적입니다.
*   **버전 관리 용이:** 애플리케이션과 웹 서버의 버전이 함께 관리되므로, 호환성 문제를 줄이고 특정 웹 서버 버전에 대한 의존성을 명확히 할 수 있습니다.

### 3. 실무에서 주의할 점 및 커스터마이징 방법

내장 웹 서버의 설정은 주로 `application.properties` 또는 `application.yml` 파일을 통해 커스터마이징할 수 있습니다.

*   **포트 설정:**
    *   `server.port=8081`
    *   기본 포트(8080) 대신 원하는 포트로 변경할 수 있습니다.
*   **스레드 풀 설정 (Tomcat 기준):**
    *   `server.tomcat.threads.max=200` (최대 스레드 수)
    *   `server.tomcat.threads.min-spare=10` (최소 유휴 스레드 수)
    *   애플리케이션의 동시 요청 처리량과 성능 요구사항에 맞춰 스레드 풀 크기를 조절하여 최적의 성능을 확보할 수 있습니다. 너무 적으면 병목이 발생하고, 너무 많으면 불필요한 자원 소모가 발생할 수 있습니다.
*   **SSL 설정:**
    *   `server.ssl.enabled=true`
    *   `server.ssl.key-store=classpath:keystore.p12`
    *   `server.ssl.key-store-password=password`
    *   `server.ssl.key-store-type=PKCS12`
    *   HTTPS 통신을 위해 SSL/TLS 인증서를 설정할 수 있습니다. 이를 통해 데이터 암호화 및 보안을 강화할 수 있습니다.
*   **기타 설정:**
    *   `server.servlet.context-path=/api` (컨텍스트 경로 설정)
    *   `server.max-http-header-size=8KB` (HTTP 헤더 최대 크기)
    *   `server.connection-timeout=20000` (연결 타임아웃)
    *   이 외에도 다양한 웹 서버 관련 설정을 통해 애플리케이션의 동작 방식을 세밀하게 제어할 수 있습니다.

**주의할 점:**

*   **과도한 커스터마이징 지양:** Spring Boot의 장점 중 하나는 "Convention over Configuration"이므로, 특별한 이유가 없다면 기본 설정을 따르는 것이 좋습니다.
*   **성능 튜닝:** 스레드 풀과 같은 성능 관련 설정은 실제 부하 테스트를 통해 적절한 값을 찾아야 합니다. 무작정 값을 변경하기보다는 애플리케이션의 특성과 예상 트래픽을 고려해야 합니다.
*   **보안:** SSL 설정 시 키스토어 파일과 비밀번호는 안전하게 관리해야 합니다.
*   **운영 환경 고려:** 운영 환경에서는 로드 밸런서나 API 게이트웨이 앞에서 Spring Boot 애플리케이션이 실행되는 경우가 많으므로, 웹 서버의 일부 설정(예: 포트)은 외부 인프라와 연동하여 고려해야 합니다.
