# [Q163] Spring의 @Controller와 @RestController 차이

## @Controller와 @RestController 애노테이션

### 1. 핵심 정의

*   **`@Controller`**: Spring MVC의 컨트롤러를 나타내는 애노테이션입니다. 주로 View를 반환하는 웹 애플리케이션에서 사용됩니다.
*   **`@RestController`**: `@Controller`와 `@ResponseBody`를 결합한 애노테이션입니다. RESTful 웹 서비스 개발에 특화되어 있으며, 메서드의 반환 값을 HTTP 응답 본문으로 직접 직렬화하여 전송합니다.

### 2. 동작 원리 및 주요 차이점

*   **`@Controller`**:
    *   **동작 원리**: `@Controller`가 붙은 클래스의 메서드는 일반적으로 `View` 이름(예: "index.html", "userList.jsp")이나 `ModelAndView` 객체를 반환합니다. Spring MVC의 `ViewResolver`가 이 반환 값을 해석하여 실제 View를 찾아 렌더링하고, 그 결과를 HTTP 응답으로 클라이언트에 전송합니다.
    *   **주요 차이점**: View 렌더링을 목적으로 하며, 기본적으로 HTTP 응답 본문에 직접 데이터를 쓰는 것이 아닙니다. 특정 메서드에 `@ResponseBody`를 추가하면 해당 메서드만 응답 본문으로 데이터를 직렬화하여 전송할 수 있습니다.

*   **`@RestController`**:
    *   **동작 원리**: `@RestController`는 클래스 레벨에 `@ResponseBody`가 적용된 것과 동일하게 동작합니다. 따라서 이 애노테이션이 붙은 클래스의 모든 메서드는 반환하는 객체를 HTTP 응답 본문으로 직접 직렬화하여 전송합니다. Spring은 기본적으로 `HttpMessageConverter`를 사용하여 자바 객체를 JSON, XML 등 클라이언트가 요청한 형식으로 변환합니다.
    *   **주요 차이점**: ViewResolver를 통한 View 렌더링 과정을 거치지 않고, 메서드의 반환 값을 바로 HTTP 응답 본문으로 변환하여 전송합니다. 이는 RESTful API의 핵심 원칙인 "자원(Resource) 표현"에 부합합니다.

### 3. RESTful API 개발 시 @RestController의 이점 및 내부 동작 방식

*   **RESTful API 개발 시 이점**:
    *   **코드 간결성**: 모든 메서드에 `@ResponseBody`를 일일이 붙일 필요 없이, 클래스 레벨에서 한 번의 선언으로 모든 메서드가 RESTful 응답을 생성하도록 합니다.
    *   **명확한 역할 분리**: 해당 컨트롤러가 View를 반환하는 것이 아니라 데이터(JSON, XML 등)를 반환하는 REST API임을 명확히 나타냅니다.
    *   **생산성 향상**: API 개발에 필요한 상용구 코드를 줄여 개발 생산성을 높입니다.

*   **내부 동작 방식**:
    *   `@RestController`는 내부적으로 `@Controller`와 `@ResponseBody` 애노테이션을 메타 애노테이션으로 포함하고 있습니다.
    *   Spring MVC는 요청을 처리할 때, `@ResponseBody`가 붙은 메서드의 반환 값을 처리하기 위해 `RequestMappingHandlerAdapter`를 사용합니다.
    *   `RequestMappingHandlerAdapter`는 등록된 `HttpMessageConverter` 목록을 순회하며, 반환 타입을 직렬화할 수 있는 적절한 `HttpMessageConverter`를 찾아 객체를 HTTP 응답 본문으로 변환합니다.
    *   일반적으로 JSON 직렬화를 위해 Jackson 라이브러리의 `MappingJackson2HttpMessageConverter`가 사용되며, XML 직렬화를 위해서는 JAXB 또는 Jackson XML 모듈 기반의 컨버터가 사용될 수 있습니다. 이 과정에서 HTTP `Accept` 헤더를 통해 클라이언트가 원하는 응답 형식을 파악하여 적절한 컨버터를 선택합니다.
